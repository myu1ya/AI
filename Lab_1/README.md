# Лабораторная работа №1: Введение в машинное обучение и подготовка данных

## Описание датасета
В качестве исходного набора данных выбран **Bank Marketing Dataset**. Он содержит информацию о клиентах банка и результатах маркетинговой кампании. Основной задачей является прогнозирование того, откроет ли клиент срочный банковский депозит после проведения маркетинговой кампании. Целевой переменной в данном случае является депозит. В датасете представлены характеристики клиентов, сведения об их финансовом положении, занятости и результаты взаимодействия с банком.

## Бизнес-задача
Банк проводит маркетинговые кампании для привлечения клиентов к оформлению срочных депозитов и основная проблема заключается в том, что обращение ко всем клиентам требует значительных ресурсов, при этом далеко не каждый клиент заинтересован в предложении, поэтому бизнес-задача заключается в разработке модели, которая сможет прогнозировать вероятность оформления клиентом срочного депозита на основе имеющихся характеристик.
Использование такой модели позволит выделять клиентов с большей вероятностью положительного ответа, эффективнее планировать маркетинговые кампании, рациональнее использовать ресурсы банка.

## Основные этапы
В ходе лабораторной работы выполняются следующие этапы:
1. Загрузка библиотек
2. Загрузка и первичный анализ датасета
3. Анализ структуры и размерности данных
4. Удаление признаков, не несущих пользы
5. Разведочный анализ данных (EDA)
6. Группировка данных с помощью `groupby`
7. Визуальный анализ распределения возраста клиентов с помощью `boxplot`
8. Преобразование категориальных признаков методом One-Hot Encoding
9. Разделение данных на обучающую и тестовую выборки
10. Масштабирование числовых признаков с помощью `StandardScaler`
11. Обучение модели `RandomForestClassifier`
12. Получение прогнозов на тестовой выборке
13. Оценка качества модели с помощью метрики `Accuracy`
14. Формулирование бизнес-вывода

В работе используются библиотеки Pandas - обработка и анализ данных, NumPy - работа с числовыми данными, Matplotlib - построение графиков, Seaborn - визуализация данных, Scikit-learn - предварительная обработка данных, построение и оценка модели, Random Forest — алгоритм классификации.

## Результаты визуального анализа
В ходе разведочного анализа было рассмотрено распределение возраста клиентов в зависимости от результата маркетинговой кампании. Анализ показал, что распределения двух групп имеют значительное пересечение и одного показателя баланса недостаточно для точного прогнозирования решения клиента, поэтому при построении модели необходимо учитывать совокупность различных характеристик клиентов

## Модель машинного обучения
Для решения задачи бинарной классификации используется алгоритм **Random Forest Classifier**. Перед обучением модели категориальные признаки преобразуются с помощью One-Hot Encoding. Данные разделяются на обучающую и тестовую выборки в соотношении 80/20. При разделении используется параметр `stratify`, позволяющий сохранить соотношение классов целевой переменной. Числовые признаки масштабируются с помощью `StandardScaler`, параметры масштабирования рассчитываются только на обучающей выборке, что позволяет избежать утечки информации из тестовой выборки.

## Оценка модели
Качество классификации оценивается с помощью метрики **Accuracy**. Accuracy показывает долю объектов тестовой выборки, для которых модель правильно определила результат.
**Итоговое значение Accuracy: 80.58%**

## Бизнес-вывод
Построенная модель позволяет прогнозировать решение клиента об открытии срочного банковского депозита на основе его характеристик и результатов маркетинговой кампании. Полученный результат может использоваться банком для более точного выбора целевой аудитории маркетинговых кампаний. Вместо массовой рассылки предложений банк может сосредоточить внимание на клиентах, для которых модель прогнозирует более высокую вероятность оформления депозита. Это позволит рациональнее использовать маркетинговый бюджет, сократить количество неэффективных обращений и потенциально повысить результативность кампаний. Для дальнейшего улучшения модели нужно использовать дополнительные метрики качества классификации и провести более подробный анализ важности признаков.
