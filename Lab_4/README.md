# Лабораторная работа №4: Линейные модели классификации и регрессии: аналитическое и итеративное решение

В работе рассматривается применение линейных моделей машинного обучения для решения задачи прогнозирования индивидуальных медицинских расходов клиентов страховой компании

## Описание датасета: В качестве исходного набора данных используется Medical Cost Personal Dataset. Датасет содержит сведения о клиентах - возраст, пол, индекс массы тела, количество детей, регион проживания, наличие привычки курения и сумму медицинских расходов

## Бизнес-задача: прогнозирование медицинских расходов клиентов на основе их характеристик, а также определение факторов, оказывающих наибольшее влияние на размер расходов. Полученные результаты могут использоваться страховыми компаниями для оценки рисков и формирования страховых предложений

На этапе подготовки данных пропущенные значения возраста заполнены медианой, категориальные признаки закодированы методом One-Hot Encoding. Данные разделены на обучающую и тестовую выборки в соотношении 80/20. Выполнено масштабирование признаков с помощью StandardScaler. Для классификации клиентов на группы с медицинскими расходами выше и ниже медианного значения обучена модель логистической регрессии. Вероятностные предсказания получены с помощью predict_proba, точность классификации (Accuracy) составила 0,9104. Для прогнозирования медицинских расходов обучены две модели: LinearRegression (аналитический метод) и SGDRegressor (итеративная модель)

## Результаты сравнения моделей:
МНК: RMSE = 5796,28; R2 = 0,78; время обучения = 0,00100 сек
SGD: RMSE = 5796,14; R2 = 0,78; время обучения = 0,09175 сек
Обе модели показали практически одинаковое качество прогнозирования, однако аналитический метод обучился быстрее

Анализ коэффициентов линейной регрессии показал, что наибольшее положительное влияние на размер медицинских расходов оказывает курение. Также заметное влияние имеют возраст, индекс массы тела и количество детей. Коэффициенты признаков пола и региона сравнительно невелики. Интерпретируемость линейной модели позволяет определить, какие характеристики связаны с увеличением или уменьшением медицинских расходов. Это помогает страховой компании объяснять результаты прогнозирования, оценивать факторы риска и принимать более обоснованные решения при формировании страховых предложений. При этом коэффициенты отражают зависимости, выявленные моделью, а не доказывают причинно-следственные связи
