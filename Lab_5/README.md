# Лабораторная работа №5: Регуляризация линейных моделей и проблема мультиколлинеарности

## Описание проекта

В работе сравниваются обычная линейная регрессия, Ridge, Lasso и ElasticNet. Цель - посмотреть, как регуляризация меняет веса признаков и качество предсказания

## Датасет

Используется Ames Housing - данные о продаже домов. Для обучения выбраны 6 признаков:
-Качество дома
-Год постройки
-Жилая площадь
-Количество ванных комнат
-Вместимость гаража
-Площадь гаража

Целевая переменная - цена продажи дома SalePrice

Корреляция площади и вместимости гаража равна 0,89. Эти признаки сильно связаны между собой, поэтому подходят для изучения мультиколлинеарности

## Бизнес-задача

Предсказать стоимость дома по его характеристикам и проверить, можно ли упростить модель без большой потери качества прогноза

## Результаты и выводы

R2 для OLS: 0.7754
R2 для Ridge: 0.7750
R2 для Lasso: 0.7751
R2 для Lasso: 0.7573
R2 для ElasticNet: 0.7746

Ridge немного уменьшила большинство весов, LassoCV сохранила все 6 признаков. Качество этих моделей получилось близким к обычной линейной регрессии
Lasso со штрафом 5000 обнулила вес количества ванных комнат. Модель стала использовать 5 признаков, но R2 снизился на 0,0181. Получилась более простая модель, которая предсказывает цену немного хуже
