# Лабораторная работа №3: Метрики качества, кросс-валидация и пайплайны

## Описание датасета
В качестве исходного набора данных используется Medical Cost Personal Dataset (insurance.csv). Датасет содержит сведения о клиентах: возраст, пол, индекс массы тела (BMI), количество детей, регион проживания, наличие привычки курения и сумму медицинских расходов (charges).
В работе рассматриваются две задачи машинного обучения: классификация для прогнозирования признака smoker и регрессия для прогнозирования суммы медицинских расходов charges

## Бизнес-задача
Медицинским страховым компаниям важно оценивать характеристики клиентов, которые могут быть связаны с медицинскими расходами. Модель классификации позволяет прогнозировать вероятность того, что клиент курит, а модель регрессии оценивать возможную сумму его медицинских расходов на основе выбранных характеристик.
Такие модели могут использоваться для предварительного анализа данных и выявления закономерностей. При этом прогнозы не должны быть единственным основанием для принятия решений о страховании или стоимости услуг

## Основные этапы
В ходе лабораторной работы выполняются следующие этапы:
1. Загрузка необходимых библиотек и датасета
2. Первичный анализ данных и проверка распределения целевого признака
3. Разделение данных на обучающую и тестовую выборки в соотношении 80/20
4. Подготовка числовых и категориальных признаков с помощью ColumnTransformer
5. Заполнение пропущенных значений с использованием SimpleImputer
6. Масштабирование числовых признаков с помощью StandardScaler и кодирование категориальных признаков через OneHotEncoder
7. Объединение предобработки и алгоритма машинного обучения в Pipeline
8. Подбор гиперпараметров модели классификации с помощью GridSearchCV и пятикратной стратифицированной кросс-валидации
9. Подбор гиперпараметров модели регрессии с помощью RandomizedSearchCV и пятикратной кросс-валидации
10. Оценка моделей с помощью метрик качества и визуализация результатов
11. Формулирование вывода
В работе используются Pandas и NumPy для обработки данных, Matplotlib и Seaborn для визуализации, а также Scikit-learn для подготовки данных, построения моделей и оценки их качества

## Выбранные метрики качества
Precision - показывает, какая доля клиентов, отнесённых моделью к курящим, действительно курит
Recall - показывает, какую долю всех курящих клиентов удалось обнаружить
F1-score - учитывает баланс между Precision и Recall
ROC-AUC = 0.9561 - оценивает способность модели различать классы
MAE, MSE, RMSE, SMAPE - характеризуют ошибки прогнозирования медицинских расходов 
MSE = 135,085,905 квадратных $ - средняя квадратичная ошибка, сильнее штрафует большие отклонения; RMSE = 11,623 $- квадратный корень из MSE, выраженный в тех же единицах, что и целевой признак; MAE = 9,114.98 - средняя абсолютная ошибка прогноза; SMAPE = 72.60% - симметричная средняя абсолютная процентная ошибка. Чем меньше значения этих метрик, тем ближе прогнозы к фактическим значениям

## Визуальный анализ
На графике фактических и прогнозируемых расходов видно, что модель недостаточно точно оценивает большие суммы и чаще завышает небольшие расходы. Распределение ошибок показывает преобладание отрицательных значений, то есть модель чаще завышает прогнозируемые расходы относительно фактических. Получается, модель имеет ограниченную точность и нуждается в дополнительной настройке

## Финальный экономический вывод
Модель классификации показала Accuracy 0,92 и ROC-AUC 0,9561. При этом допущено 3 ошибки 1 рода (FP) и 19 ошибок 2 рода (FN). Первые могут привести к необоснованному завышению оценки расходов некурящих клиентов, а вторые к недооценке расходов курящих клиентов и финансовым потерям страховой компании. Precision для класса курящих составляет 0,92, а Recall - 0,65. Чтобы выявлять больше курящих клиентов, можно повысить чувствительность модели, однако это может увеличить число ложноположительных результатов. Выбор баланса зависит от стоимости каждого типа ошибки для бизнеса. Модель можно использовать для предварительного анализа клиентов, но перед практическим внедрением необходимо улучшить Recall и оценить финансовые последствия ошибок. Регрессионная модель показала MAE около 9 150,89 долларов и SMAPE 71,18%, что указывает на значительную погрешность прогнозирования. Поэтому её целесообразно использовать для предварительной оценки расходов, но не как единственный инструмент принятия финансовых решений
Обе модели полезны для анализа данных, однако для полноценного применения в бизнесе требуется дополнительная настройка и проверка качества прогнозов
