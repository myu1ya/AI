# Лабораторная работа №2: Метод k-ближайших соседей и непараметрические методы регрессии

## Описание датасета
В качестве исходного набора данных выбран **Used Car Price Prediction**.
Датасет содержит информацию об автомобилях с пробегом и их характеристиках. Основной задачей является прогнозирование стоимости автомобиля на основе доступных признаков

## Бизнес-задача
Основная проблема при продаже и покупке автомобилей с пробегом заключается в необходимости определить их справедливую рыночную стоимость. Ручная оценка стоимости может занимать значительное время и зависеть от субъективного мнения специалиста, поэтому бизнес-задача заключается в разработке модели, которая сможет прогнозировать стоимость автомобиля на основе его характеристик.
Использование такой модели позволит автоматизировать предварительную оценку автомобилей, быстрее формировать ценовые предложения, сравнивать автомобили между собой и рациональнее принимать решения при покупке и продаже транспортных средств.

## Основные этапы
В ходе лабораторной работы выполняются следующие этапы:
1. Загрузка библиотек
2. Загрузка и первичный анализ датасета
3. Удаление признаков, не несущих пользы (название автомобиля)
4. Разведочный анализ данных (EDA)
5. Группировка данных с помощью `groupby`
6. Масштабирование числовых признаков с помощью `StandardScaler`
7. Подбор оптимального количества соседей `k` для модели `KNeighborsRegressor`
8. Сравнение Евклидовой и Манхэттенской метрик расстояния
9. Реализация ядерной регрессии Надарая–Ватсона
10. Подбор оптимального значения `gamma`
11. Оценка качества моделей с помощью метрик `MAE` и `R2`
12. Формулирование бизнес-вывода

В работе используются библиотеки Pandas — обработка и анализ данных, NumPy — работа с числовыми данными, Matplotlib — построение графиков, Seaborn — визуализация данных, Scikit-learn — предварительная обработка данных, построение и оценка моделей, KNeighborsRegressor — алгоритм регрессии методом k-ближайших соседей, rbf kernel — гауссовское ядро для ядерной регрессии.

## Модель машинного обучения
Для решения задачи регрессии используется алгоритм **KNeighborsRegressor**. Перед обучением модели категориальные признаки преобразуются с помощью One-Hot Encoding. Данные разделяются на обучающую и тестовую выборки в соотношении 80/20. Числовые признаки масштабируются с помощью `StandardScaler`, параметры масштабирования рассчитываются только на обучающей выборке, что позволяет избежать утечки информации из тестовой выборки. Для модели kNN был выполнен подбор оптимального количества соседей `k` = 13. После этого проведено сравнение Евклидовой (`p=2`) и Манхэттенской (`p=1`) метрик расстояния. Дополнительно была реализована ядерная регрессия Надарая–Ватсона с использованием гауссовского ядра и для неё было подобрано оптимальное значение параметра `gamma`.

## Оценка модели
Качество моделей оценивается с помощью метрик **MAE** и **R2**. MAE показывает среднюю абсолютную ошибку прогнозирования стоимости автомобиля, а R2 характеризует, насколько хорошо модель объясняет изменение целевой переменной.

Для Евклидовой метрики расстояния получены следующие результаты:
**MAE: $6 357,46**  
**R2: 0,24**

Для Манхэттенской метрики:
**MAE: $6 454,15**  
**R2: 0,22**

Следовательно, Евклидово расстояние показало лучший результат, по сравнению с Манхэттенским расстоянием при k = 13

Для ядерной регрессии Надарая–Ватсона оптимальным оказалось значение `gamma = 4,89`.
**MAE: $6 020,82**  
**R2: 0,49**

Это лучший результат среди остальных метрик, данные значения используются для визуализации

## Бизнес-вывод
В результате сравнения двух метрик расстояния модель kNN с Евклидовой метрикой показала лучший результат, в данном датасете Евклидова метрика работает немного эффективнее. Лучший результат показала ядерная регрессия Надарая–Ватсона, получается эта модель точнее двух рассмотренных вариантов kNN. Полученные результаты показывают, что модель способна выявлять зависимость стоимости автомобиля от его характеристик, но точность прогнозирования остаётся ограниченной, так как данные датасета нуждаются в дополнительной обработке, поэтому её не целесообразно использовать как единственный источник определения цены.
